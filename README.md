# mock-excel-report

Excel帳票に「お金①」「お金②」「名前」「日付」の4項目を埋め込んで返すモックサーバー。
DBは見ず、リクエストボディの値（未指定ならダミー値）を使う。

## セットアップ

```
npm install
```

## テンプレートについて

`templates/template.xlsx` を**サーバー起動前に配置**しておく（サーバー自身はExcelを生成しない）。
リポジトリには動作確認用のサンプルテンプレートが入っているので、そのまま使うか、
自分のテンプレートに差し替えて良い。

セル位置は固定していない。**プレースホルダー方式**を採用しており、
どのセルでも構わないので、以下の文字列をテンプレート内に書いておけば
サーバーが全セルを走査して自動的に該当箇所を探し出して置換する。

| 項目   | プレースホルダー（いずれでも可）         |
|--------|--------------------------------------------|
| 日付   | `${date}` / `${日付}`                       |
| 名前   | `${name}` / `${名前}`                       |
| お金① | `${money1}` / `${お金1}` / `${お金①}`     |
| お金② | `${money2}` / `${お金2}` / `${お金②}`     |

- セル全体がプレースホルダーだけの場合（例: セルの値が `${money1}` のみ）は、
  数値としてそのまま置換されるので、あらかじめ設定したセルの表示形式（`#,##0"円"`など）がそのまま活きる。
- `${name}　御中` のように文中に埋め込むこともできる（その場合は文字列として置換される）。
- 行・列・シート構成やセル位置がテンプレート側で変わっても、プレースホルダーさえ書いてあれば
  `server.js` の修正は不要。

新しいエイリアスを追加したい場合は `server.js` の `ALIASES` を編集する。

### 他の実現方法（参考）

今回はモックとして手軽なプレースホルダー文字列方式を採用したが、他にも:

- **名前付き範囲（Defined Name）**: Excel側で「名前の定義」機能を使いセルに`money1`等の名前を付け、
  exceljsの`definedNames`から探して埋める。より「正式」だがテンプレート作成側にExcelの知識が要る。
- **テンプレートエンジン系ライブラリ**（`xlsx-template`, `carbone.io`等）: `{d.money1}`のような構文で
  ループや条件分岐にも対応できる。明細行数が可変の帳票など、より複雑なケースに強い。

サンプルテンプレートを作り直したい場合:

```
npm run build-template
```

## 起動

```
npm start
```

起動後、ブラウザで `http://localhost:3000/` を開くとアップロード画面が使える。

- テンプレート(.xlsx)を選択(未選択ならサンプルテンプレートを使用)
- 日付・名前・お金①・お金②を入力(空欄はダミー値)
- 「帳票を生成してダウンロード」を押すと `report.xlsx` がダウンロードされる

## API

`POST /api/report/generate`

`multipart/form-data`（アップロード画面はこちら）または `application/json` を受け付ける。

- `template`: テンプレートファイル（multipartのみ、省略時はサンプルテンプレートを使用）
- `date` / `name` / `money1` / `money2`: すべて省略可（省略時はダミー値）

```json
{
  "date": "2026年09月01日",
  "name": "サンプル株式会社",
  "money1": 150000,
  "money2": 32000
}
```

レスポンス: プレースホルダーを置換した `report.xlsx` がダウンロードされる。

## 動作確認例

```
curl -o report.xlsx -X POST http://localhost:3000/api/report/generate \
  -H "Content-Type: application/json" \
  -d '{"money1":98000,"money2":15000,"name":"テスト商事株式会社"}'
```

※ Windows(Git Bash)で`-d`に日本語を直接渡すと文字化けすることがあるため、
その場合はJSONファイルを作って `--data-binary @payload.json` で送るのが確実。
