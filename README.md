# mock-excel-report

Excel帳票(.xlsx)に住所・氏名・利用期間などの項目を埋め込んで返すモックサーバー。
アップロード画面/ダウンロード画面の2画面(切り替え式)を持ち、
「ファイル選択→保存」の2段階でテンプレートを登録し、保存一覧からダウンロードできる。
DBは見ず、サーバー内に固定で持っているモックデータを使う。今回はExcelのみ対応。

## セットアップ

```
npm install
```

## 起動

```
npm start
```

起動時に `templates/` ディレクトリ(テンプレートの保存先)が自動的に用意される。
ブラウザで `http://localhost:3000/` を開くと画面が使える。上部のタブで
「アップロード画面」「ダウンロード画面」を切り替える。

### アップロード画面

1. **① ファイルを選択**: `.xlsx` を複数選択できる。選んだ時点では**まだサーバーには送られず**、
   下に「選択中のファイル」として一覧表示されるだけ(1段階目)。一覧からは個別に削除もできる。
2. **② 保存する**: ボタンを押すと選択中のファイルがまとめてサーバーに送られ、検証を通ったものだけ
   `templates/` に実際に保存される(2段階目)。
3. **埋め込み可能な項目**: テンプレートに書けるプレースホルダーの一覧とサンプル値を表示。
4. **保存一覧**: 保存に成功したテンプレートがここに表示される。各行の「削除」ボタンで
   `templates/` から実際に削除できる(確認ダイアログあり)。ダウンロード画面の一覧からも同様に削除できる。

### ダウンロード画面

保存一覧が表示され、各行の「ダウンロード」ボタンでその場でプレースホルダーを
モックデータに置き換えた `.xlsx` をダウンロードできる。

## プレースホルダーの書式

`${{キー名}}` の形式(`$` + 二重中括弧)。セル内のどこに書いても、全シート・全セルを
走査して検出する。

- **1セルに複数連結**できる(住所などに使うパターン): `${{都道府県}}${{住所}}${{番地}} ${{マンションなど}}`
- **範囲表記**もできる(日付などに使うパターン): `${{開始日}} 〜 ${{終了日}}`
- セル全体が1つのプレースホルダーだけの場合は型を保持する
  (`サンプル数値`は数値のまま、`チェックボックスtrue`/`チェックボックスfalse`は真偽値のまま埋め込まれるので、
  Excel上でSUMやIF等の数式にそのまま使える)。文中に埋め込む場合は文字列表現になる
  (数値はカンマ区切り、真偽値は`true`/`false`の文字列)。
- 複数シートに対応。すべてのシートを走査する。

## 埋め込めるデータ(モック固定値)

DBは見ず、サーバー内(`server.js`の`DATA`)に固定値として持っている。

| プレースホルダー(いずれでも可) | 値 |
|--------------------------------|-----|
| `${{都道府県}}` | 東京都 |
| `${{住所}}` | 港区六本木 |
| `${{番地}}` | 1-2-3 |
| `${{マンションなど}}` / `${{マンション}}` | 六本木ヒルズレジデンスB棟101 |
| `${{姓}}` / `${{性}}` | 山田 |
| `${{名}}` | 太郎 |
| `${{開始日}}` | 2026年10月01日 |
| `${{終了日}}` | 2027年03月31日 |
| `${{サンプルテキスト1}}` | これはサンプルテキストです |
| `${{サンプル数値}}` | 190000(数値) |
| `${{チェックボックスtrue}}` | true(真偽値) |
| `${{チェックボックスfalse}}` | false(真偽値) |

新しい項目を追加したい場合は `server.js` の `DATA` / `VALUE_KINDS` / `ALIASES` を編集する。

## アップロード時のバリデーション

テンプレートを保存する際、ファイルごとに以下を行う。

1. `${{xxx}}` 形式のプレースホルダーを全シート・全セルから検出する
2. 検出した `xxx` が上記のデータ一覧(`ALIASES`)に存在しない場合、**そのファイルは保存せずエラーにする**
   (例: `${{担当者}}` のような未対応の項目があると `未対応のプレースホルダーが含まれています: ${{担当者}}` というエラーになる)
3. 複数ファイルを同時に保存しようとした場合、**ファイル単位**で判定する
   (1つがエラーでも他の正常なファイルは保存される)
4. エラーになったファイルはブラウザのダイアログ(alert)で通知され、「選択中のファイル」に残るので
   修正して再度保存できる
5. 検出したプレースホルダーの一覧はサーバーのログ(コンソール)に出力される

サンプルテンプレートを作り直したい場合:

```
npm run build-template
```

(`templates/template.xlsx`が上書きされる。住所連結・日付範囲・複数シートのデモを含む)

## 動作確認用サンプル(`samples/`)

アップロード画面の動作確認用に、あらかじめ4種類のサンプルExcelを `samples/` に用意している
(`templates/`とは別。`templates/`はアプリが実際に保存したファイルだけを置く場所)。

| ファイル | 内容 |
|---------|------|
| `sample-01-valid.xlsx` | 埋め込める項目だけを使った正常サンプル(単一シート) |
| `sample-02-error.xlsx` | 未対応のプレースホルダー `${{担当者}}` を含み、アップロード時にエラーになるサンプル(単一シート) |
| `sample-03-valid-multisheet.xlsx` | ①の内容を2枚のシートに分割したもの(全て正常) |
| `sample-04-error-multisheet.xlsx` | ②のエラー項目を**2枚目のシートだけ**に置いたもの(全シートを走査しないと検出できないことの確認用) |

アップロード画面でこれらのファイルを選んで「保存する」を押すと、①③は保存成功、②④は
エラーダイアログが出て保存されない(という動きになるはず)。

作り直したい場合:

```
npm run build-samples
```

## API

- `GET /api/templates` — 保存済みテンプレート一覧を取得(`[{id, name}]`)
- `GET /api/fields` — 埋め込み可能な項目一覧とサンプル値を取得(アップロード画面の案内表示用)
- `POST /api/templates` — テンプレートを保存する(2段階目)。`multipart/form-data`で
  `templates` フィールドに `.xlsx` を複数添付できる。レスポンスはファイルごとの結果
  (`results: [{filename, status: "ok"|"error", message?, tokens}]`)と最新の保存一覧(`templates`)
- `GET /api/report/generate/:id` — 指定した1件のテンプレートにモックデータを埋め込んでダウンロード
- `DELETE /api/templates/:id` — 指定した1件のテンプレートを `templates/` から削除。最新の保存一覧(`templates`)を返す

## 動作確認例

```
# 保存(1ファイル)
curl -s -X POST http://localhost:3000/api/templates \
  -F "templates=@templates/template.xlsx"

# 一覧取得
curl http://localhost:3000/api/templates

# ダウンロード
curl -o report.xlsx http://localhost:3000/api/report/generate/template.xlsx
```
